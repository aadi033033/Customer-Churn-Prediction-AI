# 🤖 Churn.AI - Customer Churn Prediction System


## Overview

Churn.AI is an end-to-end Machine Learning application that predicts whether a customer is likely to leave a service.

The application provides multiple ML models:

- XGBoost
- Random Forest
- Gradient Boosting
- AdaBoost
- Decision Tree
- SVM
- KNN
- Naive Bayes


## Features

✅ Multiple Machine Learning Models

✅ Interactive Streamlit UI

✅ Customer churn probability prediction

✅ AI model selection

✅ Modern dashboard interface


## Dataset Features

The model uses:

- Age
- Gender
- Tenure
- Monthly Charges
- Total Charges
- Contract Type
- Internet Service
- Tech Support
